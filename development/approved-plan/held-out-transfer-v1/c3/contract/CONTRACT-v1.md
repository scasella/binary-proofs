C3 is one independently selected assembler-authored System V AMD64 machine caller. GCC 12.2 assembles and links c3.S. This experiment makes no C-language refinement or transfer-to-compiler-generated-C claim.

The caller executes CRYPTO_memcmp(p,q,n), retains its equality bit in a callee-saved register, unconditionally executes OPENSSL_cleanse(p,n), then executes CRYPTO_memcmp(p,q,n) again on current memory. It returns 2 if the initial comparison was unequal. Otherwise it returns 1 exactly when the second comparison is equal, and returns 0 when the second comparison is unequal. Clearing happens on every path. The first result is retained across both later supplier calls.

The buffer contents and n are arbitrary in the inherited all-admissible domain, with n < 2^64. The ranges of p and q may be identical, partially overlapping in either direction, or disjoint. There is no p/q separation premise. Define Mclear(a)=0 if a lies in p[0,n), and Mclear(a)=M0(a) otherwise. The initial equality uses M0; the second equality uses Mclear. In particular, the q snapshot is zero at its overlap with p and retains M0 elsewhere. No q preservation is claimed inside the cleared p range.

For n=0, the two equalities are vacuously true, both supplier calls compare zero bytes, cleanse writes zero bytes, and the caller returns 1. There are no readable/writable/canonical/nonwrapping p/q buffer premises at n=0; the inherited span predicates discharge zero length without buffer premises.
