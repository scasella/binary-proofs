# Preregistered development experiment

Freeze this file before new proof construction. This is a restricted empirical test of unchanged Debian libcrypto interfaces in the accepted fixed post-initialization E3/E5 image, not arbitrary library applicability.

H1: additional final-linked callers consume the same public callee statements, without unfolding or executing callee bodies in caller proof construction. Fresh reconstruction of supplier proofs by the checker is required and compatible with this criterion.

H2: the same parameterized checked-run/CALL/PLT/GOT/ABI composition works for C1 and C2 and a separately selected held-out C3. Exact bytes, addresses, displacements, permissions and functional reasoning are explicit case instantiations. Adaptation for C3 is recorded as adaptation and prevents an unchanged held-out success claim.

H3: access to supplied target contracts reduces marginal measured construction effort in matched identical-byte/identical-end-theorem trials. This development series does not itself test H3. Faster fresh reconstruction does not test H3.

Case selection: inspect existing callers first. C0 is the accepted secret_equal_and_clear binary. C1 is an experimental CRYPTO_memcmp Boolean wrapper. C2 is experimental conditional cleanup after comparison, with differing write/preservation obligations. C3 is a separately selected experimental multiple-call client retaining a result and reasoning over intermediate memory. Select compatible qualified scalar instructions; disclose this restriction. Preserve arbitrary admissible input contents and lengths, misalignment, identical and partially overlapping inputs. Freeze required separation from actual written stack slots, code/GOT and protected return slots before search. Zero length has no input permission premise. No caller trace or C-language refinement theorem is required or inferred.

C1 intended behavior: return exactly ABI int 1 iff the initial n input bytes are equal, otherwise 0; preserve all memory except the actual CALL slot. Full function must prove finite actual return, every-successor access policy, stack/callee-saved/omitted-state preservation, unchanged supplier and actual linkage. Inputs need readable stable logical ranges and may overlap each other. They may overlap untouched stack reservation and the incoming return slot; they must not overlap the written nested-CALL slot. Permission predicates, nonwrapping/canonical ranges and executable/read-only loaded image are explicit. Normal entry requires RF=TF=0, DF=0, AC=0 and E5's declared architectural interpretation conditions. The actual compiled stack footprint and literal end-theorems will be independently frozen after extraction and before proof search.

Development budget: at most 180 minutes wall per C1 or C2 construction stage, including failed proof searches, with checker invocations limited to 1800 seconds, one CPU and 3 GiB where the inherited machinery enforces them. Setup, generic extraction, artifact compilation, source construction intervals, checking and coordination are recorded separately; overlapping wall intervals are not summed. These development limits are not productivity estimates. Record actual available identifiers only; model, tokens and billing unavailable through this runtime are null with reasons.

First acceptance: fresh supplier dependency reconstruction; exact frozen statements and expanded definitions; empty hypotheses/free variables; unchanged permitted three axioms; inherited closure/read-only/source and byte/image checks; opaque surface inspection; universal functionality/strict access/termination/ABI/frame; admissibility witnesses; changed-byte, wrong-GOT, model/contract and missing-proof controls on disposable copies. Partial linkage proofs or warm theorem objects are DEVELOPMENT_CHECKED, never FRESH_ACCEPTED. A timeout or missing requirement cannot pass.

Opacity evidence levels: explicit public theorem application and expanded definition allowlist; source/load inspection; ambient automation state capture where available. Source grep is inspection evidence, not formal proof-dependency isolation. Shared HOL top-level contains supplier internals during reconstruction; no capability isolation claim unless separately enforced. A missing-interface import/control must be a fresh construction attempt, not reuse of old client theorem objects.

Controlled maintenance is attempted only after first positive C1: one separately frozen concrete relink layout with unchanged supplier, new exact extraction and rebuilt caller steps. No arbitrary ASLR/relocation theorem follows. Generic surface and source must freeze before C3 selection. All failures are retained; changing a frozen case's meaning creates a new experiment identifier.
